TOTP QR Decoder

Decode a 2FA QR code image, an otpauth:// URL, a Base32 secret or a Google Authenticator export QR code and get the current one-time codes. Everything runs in your browser: nothing is uploaded.

For your own accounts only.

What you can decode

What you can decode here

A QR code image
PNG, JPG, JPEG, GIF, BMP or WebP. Drag the file onto the upload area, click Browse files, or paste the image with Ctrl+V. A screenshot works. So does a photo of another screen, for apps that block screenshots.
An otpauth:// URL
Paste the URL, for example otpauth://totp/ACME:john@example.com?secret=HXDMVJECJJWSRB3HWIZR4IFUGFTMXBOZ&issuer=ACME.
A Base32 secret
Paste the secret, for example HXDMVJECJJWSRB3HWIZR4IFUGFTMXBOZ. Spaces, dashes and lowercase letters are accepted. The secret must be at least 16 characters long.
A Google Authenticator export QR code
The otpauth-migration://offline?data= format, which holds several accounts in one QR code. The page decodes all of them at once.

For each account the page shows the current one-time code with a countdown, the Base32 secret, the full otpauth:// URL and a new QR code to scan into another app.

How to decode a Google Authenticator export QR code

  1. Export from the app. In Google Authenticator, open the ⋮ menu → Transfer accounts → Export accounts and select the accounts. One QR code holds at most ten accounts. For more, the app shows several QR codes in sequence.
  2. Capture the QR code. On Android the export screen blocks screenshots. Photograph the screen with a second phone or a camera.
  3. Decode it. Drop the photo or screenshot onto the upload area at the top of this page. If you have the otpauth-migration://offline?data=… URL as text, paste it.
  4. Import the accounts. Each account gets its own QR code and otpauth:// URL. Add the accounts to another authenticator one at a time.

The export QR code won't scan

Export about four accounts at a time. A QR code with ten accounts is dense, and a dense QR code often fails to scan from a photo taken at an angle or in poor light. With fewer accounts the QR code is sparser and easier to scan. Repeat the export until every account is covered.

What is inside an otpauth-migration URL

The data parameter is base64url-encoded protobuf. It holds a MigrationPayload message with a list of OtpParameters, one entry per account. Each entry holds the raw secret bytes, the label, the issuer and the algorithm, digit-count and type enums. The format has no period field, so every exported account gets the default period of 30 seconds. This page parses the payload in the browser, skips HOTP entries and re-encodes each TOTP secret to Base32.

Move your 2FA codes to a new phone or another app

Decode the export and store the secrets somewhere you trust. Then log in to two or three accounts from the new device. Remove accounts from the old phone or wipe it only after those logins succeed: an untested secret is not a backup.

The otpauth:// URLs and per-account QR codes import into Aegis, Ente Auth, 2FAS, Bitwarden, 1Password, KeePassXC, Proton Pass and most other authenticators, one account at a time.

Two apps cannot be decoded. Microsoft Authenticator does not export its secrets. Steam Guard stores its secret in its own format, not in an otpauth:// QR code.

Is it safe to decode a 2FA QR code here?

Your QR code and secrets stay in the browser: this page has no backend to send them to. The usual advice is to never paste a TOTP secret into an online service, because most web QR decoders upload the image to a server.

jsQR reads the image on a canvas in the page, protobufjs parses export payloads and totp-generator computes the one-time codes. None of these steps sends your data over the network, and nothing is written to browser storage.

Verify it yourself

  • Open DevTools → Network, clear the list and decode something. No request carries the contents of your QR code.
  • Turn off the network after the page has loaded. Decoding still works.
  • Read the source: github.com/VizzleTF/TOTP_decoder.
  • Save the page with its scripts and open it from disk with no connection.

The page loads one analytics script: Vercel Analytics, an anonymous visit counter. It reports the page URL and does not read QR code contents, secrets or one-time codes. Its request is visible in DevTools.

When to use an offline tool instead

This page is safe only while the JavaScript you receive matches the published source. Whoever controls the hosting can serve different code. For high-value secrets, such as corporate accounts or crypto exchanges, run a local tool on an offline machine: scito/extract_otp_secrets or dim13/otpauth.

otpauth:// URL format reference

A complete TOTP URL:

otpauth://totp/ACME%20Co:john.doe@example.com?secret=HXDMVJECJJWSRB3HWIZR4IFUGFTMXBOZ&issuer=ACME%20Co&algorithm=SHA1&digits=6&period=30

Parameter Required Values Default
type yes totp | hotp —
label yes Issuer:Account, URL-encoded —
secret yes Base32, A–Z and 2–7 —
issuer no service name —
algorithm no SHA1 | SHA256 | SHA512 SHA1
digits no 6 | 8 6
period no seconds, TOTP only 30
counter HOTP only integer —

This page decodes totp URLs only. Many authenticators ignore algorithm and digits and assume SHA-1 with six digits, so a one-time code can be wrong even when the secret is right. An app that reads the URL should skip parameters it does not recognise.

Base32 secrets: length and common errors

A secret is usually 16, 26 or 32 characters long. The Base32 alphabet is A–Z and the digits 2–7. A string that contains 0, 1, 8 or 9 is not Base32, and this is the usual cause of an "invalid secret" error. Trailing = padding is optional, and case does not matter.

FAQ

Does my QR code or secret get uploaded anywhere?

No. Decoding runs in your browser, and the page has no backend. After the page loads, the only network request is an anonymous visit counter that reports the page URL.

Can I decode an export QR code with several accounts at once?

Yes. An otpauth-migration:// payload holds up to ten accounts. The page lists each account with its own one-time code, secret and QR code.

Why can't I screenshot the export QR code?

On Android, Google Authenticator marks the export screen as secure, which blocks screen capture. Photograph the screen with another device and upload the photo.

My export QR code won't scan. What do I do?

Export fewer accounts per QR code, about four. The QR code is then less dense and easier to scan from a photo.

How long should a TOTP secret be?

16 to 32 Base32 characters, which is 80 to 160 bits. This page ignores a pasted secret shorter than 16 characters. A string with digits outside 2–7 is not Base32.

My code is rejected even though the secret is right. Why?

The device clock is usually wrong: TOTP depends on the time, and a minute of drift is enough to break it. If the clock is right, check that period, digits and algorithm match what the service expects.

Can I use this to move codes into Bitwarden, Aegis or 1Password?

Yes. Each account gets a standard otpauth:// URL and a QR code, and those apps accept both.

Does it work with Microsoft Authenticator?

No. Microsoft Authenticator cannot export its TOTP secrets or show them as a QR code, so there is nothing to decode.

Does it work with Steam Guard?

No. Steam stores its shared secret in its own file format, not in an otpauth:// QR code.
